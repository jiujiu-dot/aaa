# Usagi Ate All the Colors

A color-matching battle game. Memorize a color, match it with sliders, and the closer you get, the harder you hit. Built with plain HTML, CSS and JavaScript.

**Play it here:** https://jiujiu-dot.github.io/aaa/

## How to play

1. Press **Start**. A color shows for a few seconds. Memorize it.
2. Use the **Hue**, **Saturation** and **Brightness** sliders to recreate it. You have 10 seconds.
3. Press **Attack**. The closer your color, the more damage you deal.
4. The enemy hits back for a random amount.
5. Reduce the enemy's health to 0 before yours runs out.

## Damage

| Color match | Damage |
|---|---|
| 90 to 100% | 5 |
| 80 to 89% | 4 |
| 70 to 79% | 3 |
| 60 to 69% | 2 |
| 50 to 59% | 1 |
| Under 50% | Miss |

## Features

- Turn-based battle with health bars
- Hue, saturation and brightness sliders
- Memorize timer and a 10-second guess timer
- Attack animations and floating damage numbers
- Draggable color panel
- Animated background

## Run it locally

1. Download or clone this repo.
2. Open `index.html` in your browser. No install needed.

```
git clone https://github.com/jiujiu-dot/aaa.git
```

## Built with

HTML, CSS and JavaScript. No libraries.
